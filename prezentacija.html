Pregled projekta

Što je cilj?

Domena

Chatbot odgovara isključivo na pitanja o kućnoj fermentaciji. Sva ostala pitanja odbija.

Arhitektura

RAG — model odgovara samo temeljem verificiranog sadržaja iz baze dokumenata. Nema halucinacija.

Lokalno

Niti jedan upit ne napušta lokalni sustav. Nema plaćanja, nema cloud ovisnosti.

Faza 1 — Domena

Korisnici i pravila

Ciljani korisnici

  • Početnici koji žele naučiti osnove fermentacije bez stručnog žargona
  • Entuzijasti koji traže recepte i savjete za konkretne procese
  • Korisnici koji trebaju dijagnosticirati problem ili prepoznati kvarenje

Pravila chatbota

  • Odgovara samo unutar domene fermentacije
  • Naglašava sigurnosna upozorenja
  • Prikazuje izvore odgovora
  • Jezik: isključivo hrvatski
  • Odbija pitanja izvan domene
  • Ne generira odgovore bez izvora

Struktura dokumenata

12 Markdown datoteka u /docs/ mapi. Svaka pokriva jednu temu, s YAML frontmatterom (naslov, tagovi, tip izvora) i korak-po-korak vodičima.

Ukupno: vodiči, primjeri pitanja i odgovora, pravila odgovaranja chatbota i opis RAG podataka.

Faza 2 — Tehnologija

Tehnički stack

KomponentaTehnologija
Lokalni LLMOllama + OpenEuroLLM-Croatian
Embeddingsparaphrase-multilingual-MiniLM-L12-v2
Vektorska bazaChromaDB — lokalna, perzistentna
BackendFlask 3.0 — port 3000
FrontendHTML / CSS / JavaScript
ChunkingMarkdown naslovi — ~600 znakova, 80 overlap

Zašto OpenEuroLLM Croatian?

  • Nativna kvaliteta hrvatskog jezika
  • Lokalno izvršavanje bez cloud API-ja
  • Jednostavna Ollama integracija

Zašto MiniLM-L12-v2?

  • Višejezičan model — dobro radi s hrvatskim
  • Mali i brz za lokalni rad
  • Isti model u ingest-u i retrieval-u
Faza 2 — Arhitektura

RAG pipeline

Priprema — ingest.py

1Učitaj MD datoteke iz /docs/
2Parsiraj YAML frontmatter (title, tags, tip)
3Split teksta po Markdown naslovima
4Vektorizacija — SentenceTransformer
5Pohrana u ChromaDB s metapodacima

Upit korisnika — app.py

6Korisnik pošalje pitanje iz browsera
7Embedding upita — isti model kao ingest
8ChromaDB similarity search — top-4 chunkova
9Prompt = sistemske upute + kontekst + upit
10Ollama generira odgovor — Flask vraća + izvore

Faza 2 — Obrazloženje

Zašto potpuno lokalno?

Privatnost

Niti jedan upit ne napušta lokalni sustav. Idealno za osjetljive primjene i demonstracije.

Troškovi

Nema API ključeva, nema plaćanja po upitu. Neograničeno korištenje bez financijskog ograničenja.

Dostupnost

Radi bez internetske veze. Jednom postavljeno, uvijek dostupno — nema ovisnosti o cloud servisu.

Transparentnost

Sve komponente su vidljive i izmjenjive. Savršeno za demonstraciju i razumijevanje RAG arhitekture.
